# Abdullah Shahid - Personal Portfolio Website

This repository contains the personal portfolio of **Abdullah Shahid**, a Full Stack .NET Developer based in Lahore, Pakistan. It presents selected full-stack, frontend, backend, and real-time application work through interactive project showcases and case studies.

## About

Abdullah works with ASP.NET Core, C#, Entity Framework Core, SQL Server, React.js, JavaScript, and MVC architecture. His professional experience includes production HR systems, enterprise portals, REST APIs, JWT authentication, role-based access control, CRUD workflows, SQL queries, and stored procedures.

## Features

- Responsive personal portfolio built with React.
- Interactive hero, technology, services, and project sections.
- Project filtering and detailed project case studies.
- Animated project showcase and 3D technology presentation.
- Contact form and links to project repositories and live products.
- Accessible navigation and responsive layouts.

## Getting Started

Clone the repository and install its dependencies:

```bash
git clone https://github.com/Abdullahmughal123/Abdullah-Shahid-Portfolio-Website.git
cd Abdullah-Shahid-Portfolio-Website
npm install
```

Start the development server:

```bash
npm run dev
```

Build the production bundle with:

```bash
npm run build
```
